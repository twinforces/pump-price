# Pump Price

A [GrumpyTechBro](https://x.com/GrumpyTechBro) joint.

Web game that simulates gasoline, diesel, and other consumer prices.

This repo is in **Architect** mode. There is no playable build yet. The design is not locked. Do not treat guesses in the briefing as decisions.

## Read this first

- [docs/BRIEFING.md](docs/BRIEFING.md): what we know, what we do not, and the questions that block implementation.
- [docs/RECENTGOALS.md](docs/RECENTGOALS.md): the live scratchpad.
- [docs/CHANGELOG.md](docs/CHANGELOG.md): durable history, including dead ends.

Sibling, not a spec: [Hormuz Toll](https://github.com/twinforces/hormuzboardgame) already teaches price as an industrial outcome. Reuse its habits only if this game wants the same shape (model with no view, receipts, one sitting).

## Process

Work runs under the [Ringmaster](https://github.com/twinforces/grokdevprompts) pack: Architect, then Implementer, Reviewer, Tester. Hygiene lives in `docs/`.
